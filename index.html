战态公式（团队版）

IVI 意图真实度 = Sp·ln(Fback+1) / (你的投入·(Pface+0.05))
  ＞1 真配合（口头推脱也别慌）；＜0.5 真不靠谱，止损。
SPE 协作势能 = (你的纵深/对方纵深)·(对方延迟/你的延迟)
  ＜0.6 高危低位（你被拿捏，启动极简/留痕）；0.8–1.5 健康均势。
窗口指数 W（EWS 简化代理）= Cp·0.4 + Fback·0.3 + Backstage·0.3
  ＞0.6 可推进：发起对齐/请托的良机；久不推进会归零。

综合研判：SPE＜0.6 或 IVI＜0.5 → 止损/重建（红）；W＞0.6 且 IVI＞0.8 → 可推进（绿）；其余 → 维持/拉扯（黄）。

用法

1. 【人物卡】每深交一位建一行，滑杆打分。
2. 【接触史】每次实质接触（会议/群聊/私聊/线下）记一行，回写参数快照。
3. 每周用 IVI/SPE/W 给重点人物研判，更新阶段与后续动作。
4. 纯前端、零外部依赖，离线也能用；参数基于真实行为，严禁脑补。
